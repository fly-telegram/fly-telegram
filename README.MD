<h2>⚠️ Requirements</h2>
<ul>
    <li>Python 3.9 or above</li>
    <li>Requirements from <code>requirements.txt</code></li>
</ul>

<h2>📥 Installation</h2>
<p><code>. <(wget -qO- https://raw.githubusercontent.com/fly-telegram/fly-telegram/master/install.sh)</code></p>

<h2>📦 Manual installation</h2>
<ul>
    <li><code>git clone https://github.com/fly-telegram/fly-telegram</code> : Cloning repository</li>
    <li><code>cd fly-telegram</code> : Jump to directory</li>
    <li><code>python3 -m pip install -r requirements.txt</code> : Installing requirements</li>
</ul>

<h2>🔌 Startup</h2>
<ul>
    <li><code>python3 -m fly-telegram</code> : Run the userbot with web login</li>
</ul>
